# Quickstart: 账号管理页面复刻与视图切换(006-accounts-page-revamp)

**Date**: 2026-09-25 | **Spec**: [spec.md](spec.md) | **Contract**: [ui-contract.md](contracts/ui-contract.md)

端到端验证指南:先跑自动化门禁,再按场景清单人工核对视觉与交互。视觉验收基准为参考截图(见 spec Input 描述的 Ydisks"账号管理"页)。

## 前置条件

- Windows 本机,仓库根目录 `D:\project\qing-delivery`。
- Node.js(前端工具链)与 Rust 工具链已安装;无需外部数据库/中间件。
- 已有可登录的管理员账号;系统内至少 1 个闲鱼账号(离线/未授权状态即可完成大部分核对;需验证场景可用"授权失效"账号替代观察)。

## 命令

```bash
# 自动化门禁(宪章 IV:类型检查 + 行为测试 + 构建)
cd frontend
npm run typecheck
npm run test          # vitest:过滤/排序/标签派生/分段控件/图标表
npm run build         # 产物输出 src/webui(后端内嵌)

# 启动服务(后端内嵌前端产物)
cd ..
cargo run             # 浏览器访问控制台输出的本机管理地址
```

开发热更模式(可选):`cargo run` 起后端后,另开 `cd frontend && npm run dev`,经 http://127.0.0.1:5173 访问(`/api` 由 vite 代理到后端 59189,同源语义不变)。

## 场景验证

### US1 页面框架与搜索(对照参考截图逐项核对 SC-001)

| # | 操作 | 预期 |
|---|------|------|
| 1 | 打开管理页 → 账号页 | 内容区出现大标题"账号管理"+ 副标题;顶栏/侧边导航不变 |
| 2 | 观察工具栏 | 左:搜索框占位"搜索昵称 / 备注 / 账号ID";右:双图标分段控件(无文字)+ 主按钮"扫码添加新账号"(二维码图标) |
| 3 | 观察横幅 | "当前显示 X / Y 个账号",右侧固定提示(刷新资料/二维码重新授权文案与参考一致) |
| 4 | 在搜索框输入某账号备注的一部分 | 列表即时过滤(不回车);横幅 X 变化、Y 不变 |
| 5 | 输入账号 ID 片段、昵称片段、大小写混排、首尾带空格 | 同样即时过滤;大小写与首尾空格不影响命中 |
| 6 | 清空搜索框 | 恢复全部账号,X = Y |
| 7 | 点击"扫码添加新账号" | 打开既有扫码接入弹窗;关闭不产生副作用 |

### US2 账号条目复刻

| # | 操作 | 预期 |
|---|------|------|
| 8 | 观察任一条目 | 圆形头像+右下角状态圆点;首行昵称(粗体)+徽标;次行备注(空→"暂无备注")+完整 ID |
| 9 | 造一个开启自动发货/自动平台确认的账号 | 徽标行出现"自动发货""自动平台确认";关闭的开关不出现对应徽标;**永不出现** AI/自动评价/每日擦亮(FR-008) |
| 10 | 对需验证/授权失效账号 | 条目中部红色警示文案 + 浅红底"重新授权"按钮;该账号排最前 |
| 11 | 点击"重新授权" | 打开扫码流程;授权成功后警示条与徽章消失 |
| 12 | 依次点击刷新/验证/编辑/电源/删除图标 | 分别触发:资料刷新(图标旋转)、发起验证、既有编辑弹窗、启停确认弹窗、删除确认弹窗;行为与改版前一致(FR-012) |
| 13 | 悬停每个图标 | 出现 title 文字提示 + 悬停变色;删除悬停为红色 |

### US3 图标式视图切换

| # | 操作 | 预期 |
|---|------|------|
| 14 | 观察分段控件 | 仅两个图标(列表/网格),无文字;当前视图图标高亮,`title` 有文字提示 |
| 15 | 点击另一图标 | 视图原地切换(row↔card),不整页刷新;高亮随之移动 |
| 16 | 刷新页面(F5) | 视图保持上次选择(localStorage `qing-account-view`) |
| 17 | 搜索过滤到 1 个账号后切换视图 | 两种视图都只显示该账号;异常置顶排序一致 |

### 边缘场景

| # | 操作 | 预期 |
|---|------|------|
| 18 | 搜索无匹配 | 横幅"当前显示 0 / N 个账号";列表区"无匹配账号"轻空态 + "清空搜索"按钮;非"还没有接入账号"整页空态 |
| 19 | 停后端刷新页面,或断网点击操作 | 列表区错误占位 + 重试;页头/工具栏稳定不闪烁 |
| 20 | 头像 URL 失效的账号 | 回退昵称首字占位,无破图 |
| 21 | 超长昵称/备注 | 截断省略,条目不换行破版 |

## 验收口径

- 自动化门禁三条命令全绿;新增测试覆盖 FR-003/FR-008/FR-009/FR-010 的行为断言。
- 场景 1–21 全部通过;其中 1–3、8–9 同时构成 SC-001 的"对照参考截图逐元素齐全率 100%"核对表。
- 已知限制(如实记录,不算失败):参考图的 AI/自动评价/每日擦亮徽标、机器人/日历操作图标按 FR-008 有意不复刻;顶栏文案"账号"不变(范围外)。
