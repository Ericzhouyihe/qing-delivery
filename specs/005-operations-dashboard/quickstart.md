# Quickstart: 运营概览统计首页(005-operations-dashboard)

端到端验证指南。实现完成后按本指南逐项确认;契约细节见 [contracts/stats-api.md](contracts/stats-api.md),口径见 [data-model.md](data-model.md)。

## 前置条件

- Windows 本机;Rust 工具链与 Node.js 可用。
- 无需开发环境即可运行的发布形态验证在发布阶段做;本指南覆盖开发验证。

## 构建与运行

```powershell
# 前端构建 + 后端编译运行(开发)
cd frontend; npm install; npm run build; cd ..
cargo run
# 测试
cargo test
cd frontend; npm run typecheck; npm run test; cd ..
```

启动后浏览器打开管理页(地址见运行日志),登录管理员。

## 验证场景

### S1 空库新装(对应 SC-004/FR-008)

1. 全新数据目录启动,无账号、无订单。
2. 打开概览:标题区显示"运营概览"与"系统正常运行";默认选中"7天内"。
3. 四卡显示 0 或空占位:营收 ¥0.00 无对比徽标(`change_percent=null` 不渲染 0%)、活跃账号 0/0、订单数 0、待处理 0(无警示样式)。
4. 趋势区显示空态"暂无营收数据/所选时间范围内暂无订单记录"。

### S2 口径核对(对应 SC-002/SC-005,FR-010)

1. 用 dev-fixtures 或真实扫码产生测试数据:
   - 订单 A:CNY ¥10.00,付款时间=今天;
   - 订单 B:CNY ¥25.50,付款时间=昨天;
   - 订单 C:付款后平台状态变为退款/关闭,paid_at=今天,¥8.00;
   - 订单 D:无金额(amount 为空),paid_at=今天。
2. 选"今天":营收应 = ¥18.00(A+C,D 无金额排除),订单数 = 3(A+C+D,付款事实口径,退款 C 不回冲);趋势按小时分桶,A、C 桶非零。
3. 选"7天内":营收 = ¥43.50(A+B+C),订单数 = 4;趋势按日分桶,今天与昨天两桶非零,Σ桶 = 卡值。
4. 对比徽标:构造昨天(前一区间)有数据 vs 无数据两种库状态,分别验证百分比显示与徽标隐藏;手工按 `(今-昨)/昨` 核对取整结果。

### S3 范围切换与刷新(对应 FR-002/FR-013/FR-015)

1. 依次点击 今天→昨天→三天内→7天内→一个月内:每次数值与图表原地更新、无整页刷新、无布局跳变;"昨天"趋势为小时粒度。
2. 等待 30 秒(页面保持可见):数据按当前所选范围自动刷新,范围不回落。
3. 点击"刷新"按钮:同上立即生效。

### S4 自定义区间(对应 FR-009)

1. 选"自定义",起止同一天→统计该自然日;跨两周→正常。
2. 结束早于起始→提示区间无效,不发请求、页面不变。
3. 起止跨度 >92 天(如跨 4 个月)→提示最大跨度,不发请求。
4. 自定义查询后点刷新→仍按自定义区间。

### S5 保留区块与下钻(对应 FR-014/FR-004~006)

1. 统计区下方:账号状态速览、最近待处理、最近订单三区块照常展示与下钻。
2. 点活跃账号卡→账号管理;点订单数卡→订单中心;点待处理卡→待处理工作台。

### S6 权限与只读(对应 FR-016/FR-012)

1. 未登录直接 `GET /api/v1/stats/overview?from=0&to=1` → 401。
2. `to <= from`、跨度>92 天、from/to 非数字 → 400。
3. 连续查询多次,订单/事项数据与状态无任何变化(交付、值守不受影响)。

### S7 服务停止/恢复隔离(对应 FR-001)

1. 触发停止流程:标题区状态指示变化,既有告警横幅置顶,统计仍可展示。
2. (如有恢复隔离夹具)恢复隔离横幅置顶不因改版丢失。

## 完成判据
