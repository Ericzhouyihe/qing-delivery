## User Scenarios & Testing *(mandatory)*

### User Story 1 - 概览·商品分析四区块(对照截图 1) (Priority: P1)

卖家打开概览页,在既有内容(标题区/时间筛选/五张统计卡/营收趋势/账号速览)之下,看到与 Ydisks 仪表盘一致的分析区:第一行左"商品销量排行"(横向条形排行,前三名序号高亮;空态居中"暂无数据")、右"商品下单占比"(环形图,中心显示总订单数,附图例;空态"暂无数据");第二行左通栏"参与统计的订单"(标题右上搜索框占位"搜索订单号/商品/买家...",表格列=订单信息[商品图/标题/订单号/数量]、买家信息、金额、状态徽标、操作;空态为图标+标题"当前范围内没有参与统计的订单"+口径行"日期范围:{起} 至 {止};统计口径:待发货、已发货、已完成,且订单金额不为空。当前统计卡片订单数:{N} 单。";数据多时底部提示"当前显示最近 N / M 条,搜索仅覆盖已加载明细")、右"商品金额分析 (TOP5)"(饼图+金额/百分比明细列表;空态"暂无数据")。四区块随顶部时间范围筛选联动,与统计卡同口径(仅 CNY 有金额的付款订单;退款不回冲)。

**Why this priority**: 仪表盘是卖家打开的第一屏,截图 1 即为该区域;分析区块让"哪个商品在出单"一目了然,是复刻完成度的最大缺口。

**Independent Test**: 选一个时间范围,概览下方出现四区块;造 3 笔不同商品的已付款订单后,排行/占比/TOP5 出现对应商品与数值,订单表可搜索;清空数据看四空态。

**Acceptance Scenarios**:

1. **Given** 无任何付款订单, **When** 打开概览, **Then** 四区块全部呈现且空态与截图一致("暂无数据"×3+订单表口径空态),区块标题文字与截图逐字一致。
2. **Given** 时间范围内 3 笔订单分属 2 个商品, **When** 查看排行/占比/TOP5, **Then** 商品名、件数/单数、金额与订单表一致;占比环中心=总订单数。
3. **Given** 订单表有数据, **When** 在搜索框输入订单号/商品/买家片段, **Then** 表格即时过滤;清空恢复。
4. **Given** 参与统计订单超过加载上限, **When** 查看表格底部, **Then** 出现"当前显示最近 N / M 条,搜索仅覆盖已加载明细"提示。
5. **Given** 切换时间范围(今天/7 天/自定义), **When** 数据变化, **Then** 四区块与口径行日期同步更新,无需整页刷新。

### User Story 2 - 聊天页视觉复刻(对照截图 2/3) (Priority: P2)

卖家打开在线聊天页,整体样式与 Ydisks 一致:页头左侧"在线聊天"大标题+副标题"复用账号实时连接,消息按账号完全隔离",右上"🔔 浏览器提醒"开关(真实实现:经浏览器通知权限,新消息弹系统通知;未授权/不支持时如实显示状态)与"📡 实时同步中/轮询同步中"状态胶囊(如实显示当前同步方式);账号页签带在线绿点与未读数,激活态下划线。左栏:搜索框占位"搜索用户、商品或消息"、"全部会话"标题+刷新图标;会话条目=圆形头像(无头像用首字占位)、右上相对日期、粗体昵称、灰色预览行、第三行"商品 · {商品名}"(蓝色链接样式)+右侧商品缩略图(无图占位);未读徽标与删除按钮保留。消息面板:头部对端昵称+"用户 ID: {id}",右上"账号在线/离线"胶囊;系统消息居中灰色胶囊样式([卖家已发货]/[你已确认收货,交易成功]类平台通知);买家消息灰底胶囊左对齐、自己消息右对齐,附时间戳;"加载更早消息"游标保留。输入区:左侧图标行(表情面板/图片上传[按能力门禁]/商品卡入口按能力如实隐藏)、占位文案与截图逐字一致("输入消息,Enter 发送,Shift + Enter 换行,Ctrl + V 粘贴图片")、右下圆形纸飞机发送钮。右侧快捷回复抽屉:标题"快捷回复"+副题"当前账号 · {n}/50"+右上 ✕ 收起;空态文案与截图逐字一致;底部"添加常用快捷回复..."输入+通栏"＋ 添加快捷回复"按钮;收起后输入区右侧出现展开图标(对照截图 3)。买家备注入口保留。

**Why this priority**: 聊天是使用频率最高的页面,截图 2/3 提供了完整对照基准;在 007 功能齐备基础上做视觉对齐,风险低、观感收益最大。

**Independent Test**: 打开聊天页对照截图 2 逐元素核对(页头/页签/会话条目三行结构/消息胶囊/输入区/抽屉),点 ✕ 收起抽屉对照截图 3;开启浏览器提醒后制造新消息验证系统通知。

**Acceptance Scenarios**:

1. **Given** 打开聊天页, **When** 对照截图 2 核对, **Then** 页头标题/副标题/浏览器提醒开关/同步胶囊、账号页签、会话条目三行结构、消息面板头部与"账号在线"胶囊、系统消息居中胶囊、输入区占位文案与发送钮、快捷回复抽屉标题副题与空态文案全部齐备且样式一致。
2. **Given** 抽屉展开, **When** 点击右上 ✕, **Then** 抽屉收起,输入区右侧出现展开图标(对照截图 3);再点恢复。
3. **Given** 会话有商品上下文, **When** 渲染条目, **Then** 第三行显示"商品 · {名}"链接样式与右侧缩略图;无商品上下文的会话不显示该行(不虚构)。
4. **Given** 平台通知类消息(发货/收货确认), **When** 渲染, **Then** 以居中灰色系统胶囊呈现,不左右分栏。
5. **Given** 点击"浏览器提醒"开关, **When** 授权通知权限, **Then** 新入站消息触发浏览器系统通知;拒绝或不支持时开关如实显示不可用原因。
6. **Given** 既有能力(发送四状态/未读/删除会话/买家备注), **When** 复刻后使用, **Then** 行为与 007 一致零回退。

### User Story 3 - 逐页对照走查机制(运行 Ydisks 对照) (Priority: P3)

实现过程中建立"一个一个对照"的走查闭环:优先直接对照用户提供的截图与 Ydisks 前端源码(仓库内 `Ydisks-Xianyu-Helper/frontend/` 的 Dashboard/Chat 组件——布局参数、间距、圆角、颜色、文案);如源码不足以确定视觉细节,尝试把 Ydisks 项目运行起来(其前端为标准构建,后端为 Go;运行受阻时以源码+截图为准,不阻塞)。每个复刻页面产出对照走查记录(对照来源/逐元素清单/差异与取舍),沉淀到 `docs/evidence/`,作为验收证据。

**Why this priority**: 用户明确要求"运行起来一个一个对照";把它固化为可执行任务保证复刻精度可验证,但它服务于 US1/US2,故列 P3。

**Independent Test**: 走查记录存在且每页含"对照来源(截图/源码/实机)、逐元素核对结果、差异取舍说明"。

**Acceptance Scenarios**:

1. **Given** US1/US2 实现, **When** 走查, **Then** 每页有对照记录:元素清单勾选率 100%,视觉差异均有说明(能力如实映射的取舍注明宪章依据)。
2. **Given** Ydisks 可运行, **When** 并排对照, **Then** 记录附两侧截图;不可运行时注明以源码+截图为准。

---

### Edge Cases

- 分析区块接口失败:区块内显示错误占位+重试,不影响概览其余卡片(沿用 005 降级模式)。
- 商品已删除/无标题:排行与占比显示"已删除商品"或外部 ID 截断,不虚构名称。
- 订单表商品图缺失:占位图块,不显示裂图。
- 会话无商品上下文/商品已失效:第三行不显示或显示"商品已失效",缩略图占位。
- 买家无头像:圆形首字占位(Ydisks 有平台头像,本项目无该数据,如实占位)。
- 浏览器通知权限被拒/环境不支持:开关禁用+说明,不假装开启。
- 聊天抽屉在窄窗口:收起为图标,布局不挤压消息面板(对照截图 3)。
- 深色主题:全部新增样式走既有 token,暗色自动成立;与 Ydisks 浅色截图的对应关系在走查记录注明。

## Requirements *(mandatory)*

### Functional Requirements

**概览分析区(US1)**

- **FR-001**: 概览页 MUST 在既有内容下新增分析区,四区块标题与截图逐字一致:"商品销量排行""商品下单占比""参与统计的订单""商品金额分析 (TOP5)"。
- **FR-002**: 排行 MUST 以横向条形呈现商品销量(件数合计),前三名序号高亮;占比 MUST 为环形图且中心显示总订单数、附图例;TOP5 MUST 为饼图+金额与百分比明细;三者空态均为居中"暂无数据"。
- **FR-003**: 订单表 MUST 含标题右上搜索框(占位"搜索订单号/商品/买家..."),对订单号/商品名/买家 ID 做不区分大小写子串过滤,即时生效。
- **FR-004**: 订单表空态 MUST 与截图一致:图标+"当前范围内没有参与统计的订单"+口径行"日期范围:{起} 至 {止};统计口径:待发货、已发货、已完成,且订单金额不为空。当前统计卡片订单数:{N} 单。"(日期随筛选,N 与营收卡订单数一致)。
- **FR-005**: 统计口径 MUST 与统计卡同源:所选时间范围内、待发货/已发货/已完成、CNY 且金额非空的付款订单;退款不回冲。后端 MUST 提供按商品聚合(销量/单数/金额/占比)与参与统计订单明细两个只读查询;口径实现 MUST 位于应用/领域层(传输层不做聚合,宪章 II)。
- **FR-006**: 明细 MUST 支持限量加载与截断提示"当前显示最近 N / M 条,搜索仅覆盖已加载明细"(N=已加载,M=范围内总数)。
- **FR-007**: 四区块 MUST 随概览时间范围筛选联动刷新,加载/空/错误三态齐备,错误不影响其余统计卡。

**聊天页复刻(US2)**

- **FR-010**: 聊天页头 MUST 为:左"在线聊天"标题+副标题"复用账号实时连接,消息按账号完全隔离";右"浏览器提醒"开关与同步状态胶囊(如实显示"实时同步中"或"轮询同步中";首版轮询实现显示后者,不冒充实时)。
- **FR-011**: 浏览器提醒 MUST 真实实现:开启时请求通知权限,新入站消息触发系统通知(点击聚焦页面);未授权/不支持时开关禁用并说明原因;偏好持久记忆。
- **FR-012**: 会话条目 MUST 按截图三行结构呈现:圆形头像(无头像首字占位)+右上相对日期;粗体昵称+灰色最后消息预览;"商品 · {商品名}"链接样式行+右侧商品缩略图。后端 MUST 为会话补充最后关联商品的标题与图片(取自既有商品数据;无关联则不显示该行)。
- **FR-013**: 消息面板头部 MUST 显示对端昵称+"用户 ID: {买家ID}"+右上"账号在线/账号离线"状态胶囊;系统通知类消息 MUST 以居中灰色胶囊渲染(不左右分栏),时间戳保留。
- **FR-014**: 输入区 MUST 含左侧图标行(表情面板、图片上传[能力门禁同 007]、商品卡入口——平台发送商品卡能力未验证前不显示该图标)与占位文案"输入消息,Enter 发送,Shift + Enter 换行,Ctrl + V 粘贴图片"(行为:Enter 发送/Shift+Enter 换行/Ctrl+V 粘贴图片先预览),右下圆形发送钮。
- **FR-015**: 快捷回复抽屉 MUST 为常驻右栏:标题"快捷回复"+副题"当前账号 · {n}/50"+✕ 收起钮;空态文案逐字"还没有快捷回复。把常用话术添加在下方,当前账号的所有聊天都可以使用。";底部"添加常用快捷回复..."输入+通栏"＋ 添加快捷回复"按钮(Enter 亦可提交,50 上限提示同 007);收起后输入区右侧出现展开图标。
- **FR-016**: 全部新增样式 MUST 使用既有设计 token(明暗主题自动成立),布局参数(栏宽/圆角/间距/字号)以 Ydisks 源码与截图为对照基准记录于走查文档。
- **FR-017**: 007 既有能力 MUST NOT 回退:发送四状态、未读清零与徽标、删除会话确认、买家备注、"加载更早"游标、能力门禁(图片/历史回填)全部保留。

**对照走查(US3)**

- **FR-020**: 每个复刻页面 MUST 产出对照走查记录(对照来源、逐元素清单、差异与取舍及依据),存放 docs/evidence/;Ydisks 可运行时附并排截图,不可运行时注明以源码+截图为准。

### Key Entities *(include if data model involves data)*

- **商品聚合视图(只读)**:按商品聚合的时间范围内销量(件数)、订单数、金额、占比;来源为既有订单事实,不新增可变实体。
- **参与统计订单明细(只读)**:既有订单行+商品标题/图+买家信息,限量加载。
- **会话商品上下文(只读扩展)**:会话与最后关联商品的标题/缩略图(取自既有 items 数据,展示层联出,不改会话表结构)。
- **浏览器提醒偏好**:开关状态与权限结果,本地持久。
- **快捷回复/消息/会话**:复用 007 既有实体,不改数据模型。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 概览分析区与截图 1 逐元素对照,元素齐备率 100%,四区块标题/空态/订单表口径文案逐字一致。
- **SC-002**: 聊天页与截图 2/3 逐元素对照,元素齐备率 100%;页头文案、会话条目三行结构、输入区占位文案、抽屉空态文案逐字一致;抽屉收起/展开交互与截图一致。
- **SC-003**: 分析数据与统计卡同口径:同时间范围内排行件数合计=订单表件数合计,占比中心=营收卡订单数,偏差为 0。
- **SC-004**: 浏览器提醒在授权环境下新消息通知到达率 100%;未授权时开关如实禁用。
- **SC-005**: 007 全部既有测试(后端 347/前端 294)零回退;聊天与概览既有交互零回退。
